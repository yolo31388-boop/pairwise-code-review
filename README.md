# 游戏内代码审查与静态分析系统

## 项目描述

游戏内代码审查与静态分析系统的bug修复项目。核心模块 `code/review.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 静态分析完全没做只能检查语法错误
- 代码坏味道完全没做重复代码和过长函数都检测不到
- 安全扫描完全没做SQL注入和XSS都检测不到
- 代码规范检查完全没做每个人写的代码风格都不一样
- 审查报告完全没做审查结果不能分享

## 运行测试

```bash
python -m pytest tests/test_code_review.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
